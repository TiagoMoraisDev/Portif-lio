# Tiago Morais — Portfolio Angular

Portfólio one-page em Angular standalone, com layout responsivo inspirado na referência enviada.

## Requisitos
- Node.js 20.19+ (ou versão compatível com Angular 20)
- npm

## Rodar localmente
```bash
npm install
npm start
```
Acesse `http://localhost:4200`.

## Build de produção
```bash
npm run build
```

## Personalização rápida
- Conteúdo, experiências, tecnologias e links: `src/app/app.component.ts`
- Cores, tipografia, espaçamentos e responsividade: `src/styles.css`
- Metadados e título: `src/index.html`

## Observações
- Os resultados numéricos foram transcritos do currículo fornecido.
- O monograma `TM` é um placeholder para foto/avatar. Substitua o bloco `.portrait` por uma imagem sua quando quiser.
- Revise datas, disponibilidade e links antes de publicar.
